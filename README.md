# GitKB Codex Plugin

This repository contains the GitKB marketplace plugin for Codex.

GitKB gives Codex local code intelligence first: symbols, callers, callees, impact analysis, dead-code detection, semantic search, and service-edge queries through the `git-kb` CLI and MCP tools. Full GitKB setup adds the persistent knowledge graph for tasks, specs, decisions, architecture, and team sync.

The user-facing plugin README lives at [plugin/README.md](plugin/README.md).

## Repository Layout

```text
.agents/plugins/marketplace.json      # Repo-level Codex marketplace manifest
plugin/                               # Installable Codex plugin payload
plugin/.codex-plugin/plugin.json      # Plugin manifest
plugin/hooks/hooks.json               # Codex hook registration
plugin/.mcp.json                      # GitKB MCP server registration
plugin/skills/                        # Minimal bootstrap skill
tests/                                # Packaging and policy checks
Makefile                              # Local validation and release checks
```

## Design Policy

This plugin is a thin marketplace and bootstrap wrapper. It should not become a second copy of GitKB's canonical Codex integration.

- Keep first value CLI-backed through `git-kb code ...`.
- Delegate hooks to `git-kb hook codex`.
- Keep ATC out of the plugin identity and behavior.
- Do not vendor the full `.kb/skills` set generated by `git-kb init codex`.
- Do not add broad command files that duplicate canonical GitKB workflows.
- Guide full setup through `git-kb init && git-kb init codex`.

Run the normal local checks:

```bash
make lint
make test
```

Run the complete release gate:

```bash
make release-check
```

## Manual Install Testing

From this repository, add and install the local marketplace:

```bash
codex plugin marketplace add .
codex plugin add gitkb@gitkb
```

Then open a normal Git repository in Codex and ask a code intelligence question, such as:

- "What calls `authenticate()`?"
- "Find likely dead code."
- "What's the blast radius of changing this file?"

The plugin should guide Codex toward `git-kb code ...` commands and MCP tools without requiring ATC.

## Release Readiness

Before any public release or marketplace submission:

```bash
make release-check
```

Keep this repository private while iterating. Flip visibility or mirror to a public repository only after human review confirms the package contains no proprietary code, internal-only URLs, credentials, or unreleased product details. The root `.agents/plugins/marketplace.json` points Codex at the installable plugin under `./plugin`.

## Versioning

The plugin version is declared in:

- `plugin/.codex-plugin/plugin.json`

Keep the marketplace and plugin docs aligned when preparing a release.
